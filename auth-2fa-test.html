🔐 Two-Factor Authentication (2FA) Testing

Test complete 2FA flow: Enable → Scan QR → Verify → Login with 2FA

1️⃣ Login First

ℹ️ You must login first to enable 2FA
Use your registered account credentials

2️⃣ Enable 2FA Not Enabled

⚠️ Requires Login
You must be logged in to enable 2FA

📱 Scan with Authenticator App

🔑 Manual Entry Code: Can't scan? Enter this code manually in your authenticator app
📱 Recommended Authenticator Apps:
• Google Authenticator
• Microsoft Authenticator
• Authy
• 1Password

3️⃣ Verify 2FA Setup

ℹ️ Enter the 6-digit code from your authenticator app
This confirms that 2FA is working correctly
🧪 Development Testing:

4️⃣ Login with 2FA

2FA Login Flow:
Enter email (2FA must be enabled)
Enter 6-digit code from app
Get JWT token

📚 Complete Testing Guide

1 Login with your account to get JWT token
2 Enable 2FA - You'll receive a QR code and secret key
3 Scan QR code with Google Authenticator or similar app
4 Verify setup by entering the 6-digit code from your app
5 Test 2FA login - Login using email + 2FA code (no password needed)
🧪 Development Helper:
Use the "Generate Test Code" button to get a valid 2FA code without an authenticator app. This is for testing purposes only and should be removed in production.
