============================================
HƯỚNG DẪN LẤY STRATEGY ID:
============================================
Bước 1: Đăng nhập và lấy token (API 1)
Bước 2: Gọi GET /api/bot-strategies với header Authorization: Bearer {token}
Bước 3: Từ response, copy field "id" của strategy đầu tiên
Bước 4: Thay "PASTE_STRATEGY_ID_HERE" bằng ID vừa copy

Ví dụ response (BẠN ĐÃ LẤY ĐƯỢC):
[
  {
    "id": "a1a11bc3-415d-4a5b-9da4-2e3afac22be5",  ← Strategy ID này
    "strategyKey": "grid-basic",
    "displayName": "Grid Trading",
    "description": "..."
  }
]

✅ Strategy ID của bạn: a1a11bc3-415d-4a5b-9da4-2e3afac22be5

============================================
LƯU Ý QUAN TRỌNG:
============================================
1. Token có thời hạn (thường 15-60 phút)
   - Nếu gặp lỗi 401 "token expired" → Đăng nhập lại (API 1)
   - Copy token mới và dùng cho các API tiếp theo

2. Thay PASTE_STRATEGY_ID_HERE bằng Strategy ID thực tế
   - Gọi GET /api/bot-strategies để lấy ID

3. Thay {id} bằng Bot ID thực tế
   - Lấy từ response khi tạo bot (POST /api/bots)

4. Tất cả API cần Authorization header:
   Authorization: Bearer {token}
   - Lấy token từ API login (API 1)

5. Nếu có 2FA:
   - Bước 1: Login → nhận requiresTwoFactor: true
   - Bước 2: Gọi test-generate-2fa-code để lấy mã
   - Bước 3: Gọi login-2fa với mã để lấy token
