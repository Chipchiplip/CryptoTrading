2️⃣ Reset Password

Password Reset Flow:
User enters email
System sends reset link to email
User clicks link → Opens reset page
User enters new password
Password updated ✓

3️⃣ Test Login with New Password

ℹ️ Verify password was changed:
After resetting, try logging in with your new password.

📚 Complete Testing Guide

1 Request password reset - Enter your email to receive reset link
2 Check email inbox - Click the reset link or copy the token
3 Enter new password - Use the token from email to set new password
4 Test login - Login with your new password to verify it works
🔍 API Endpoints Used:
  • POST /api/auth/forgot-password - Request reset link
  • POST /api/auth/test-get-reset-token - Get token (dev)
  • POST /api/auth/reset-password - Reset with token
  • POST /api/auth/login - Verify new password
